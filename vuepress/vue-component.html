编写 Vue 组件

VuePress 编写 Vue 组件步骤如下：

  1. 创建自定义组件
  2. 手动全局注册组件(可选)
  3. 在 Markdown 中使用自定义组件

创建自定义组件

在 .vuepress/components/ 目录下创建 MyComponent.vue 文件，内容如下：

<template>
  <div class="my-component">
    <h2>这是一个自定义组件</h2>
    <p>这是组件的内容。</p>
  </div>
</template>

<script>
export default {
  name: 'MyComponent'
}
</script>

<style scoped>
.my-component {
  border: 1px solid #eaecef;
  padding: 20px;
  margin: 1em 0;
}
</style>

注意：

  1. vuepress 1.X 和 2.X 版本的组件写法不同，请根据版本选择对应的写法，本文以 2.X 版本为例。
  2. VuePress 默认会自动注册 .vuepress/components/ 下的 Vue 组件，但需确保
    1. 组件文件名为 MyComponent.vue（大小写敏感）
    2. 路径必须是 .vuepress/components/，不能是其他路径，包括子目录。

手动全局注册组件(可选)

如果自动注册失败，可以在 .vuepress/client.js 中手动注册：

import MyComponent from './components/MyComponent.vue'

export default defineClientConfig({
    enhance({ app }) {
        app.component('MyComponent', MyComponent)
    },
})

在 Markdown 中使用自定义组件

<MyComponent></MyComponent>

卡片组件

卡片由容器 <Cards> 和单张 <Card> 组成。title 通过 prop 传入，正文写在默认插槽里；样式用 <style scoped> 内置在组件内，没有独立的样式文件。一个 <Cards> 里放多张 <Card> 即三列并排，窗口宽度 ≤719px 时折成一列。

组件代码：

Cards.vue
<template>
  <div class="cards">
    <slot />
  </div>
</template>

<script>
export default {
  name: 'Cards'
}
</script>

<style scoped>
.cards {
  display: grid;
  /* auto-fit + minmax：按容器宽度决定列数，卡片不足时多出的空轨道会被折叠，
     剩下的卡片自动撑满整行。2 张 → 各占一半，3 张 → 三等分，6 张 → 三列两行。
     下限 11rem（176px）是实测值：内容栏的卡片网格宽约 643px，刚好仍容得下 3 列。 */
  grid-template-columns: repeat(auto-fit, minmax(11rem, 1fr));
  gap: 0.75rem;
  margin: 1rem 0;
}

@media (max-width: 719px) {
  .cards {
    grid-template-columns: 1fr;
  }
}
</style>
Card.vue
<template>
  <div class="card">
    <p v-if="title" class="card-title">{{ title }}</p>
    <p class="card-text"><slot /></p>
  </div>
</template>

<script>
export default {
  name: 'Card',
  props: {
    /** 卡片标题，留空则只显示正文 */
    title: {
      type: String,
      default: ''
    }
  }
}
</script>

<style scoped>
.card {
  padding: 0.75rem 0.9rem;
  border: 1px solid var(--vp-c-border);
  border-radius: 0.4rem;
  background: var(--vp-c-bg-alt);
}

.card-title {
  margin: 0 0 0.35rem;
  font-weight: 700;
  color: var(--vp-c-accent);
}

.card-text {
  margin: 0;
  font-size: 0.9em;
  line-height: 1.65;
}
</style>

在 Markdown 中使用：

<Cards>
  <Card title="碰撞攻击">找到两个完全不同的输入，却产生相同的哈希值</Card>
  <Card title="预图像攻击">给定一个哈希值，找到生成它的那个输入</Card>
  <Card title="第二预图像攻击">给定输入 A 和它的哈希值，找到另一个输入 B（≠A）具有相同的哈希值</Card>
</Cards>

客户端配置文件

有些时候用户们可能希望直接添加一些客户端代码。 VuePress 通过客户端配置文件client.js来支持这种需求。 layouts用于注册自定义布局组件，每个布局是一个 Vue 组件（.vue 文件），自定义布局文件放在.vuepress/layouts/目录下。

import { defineClientConfig } from 'vuepress/client'

export default defineClientConfig({
  enhance({ app, router, siteData }) {},
  setup() {},
  rootComponents: [],
  layouts: {Article,Category,Tag,Timeline,},// 用于注册自定义布局组件，自定义布局文件放在.vuepress/layouts/目录下
})
