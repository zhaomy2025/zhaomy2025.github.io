### 概念速查

| 类别 | 代表 | 可逆性 | 密钥 | 用途 |
| --- | --- | --- | --- | --- |
| 编码 | Base64 | 可逆 | 无 | 让数据能走文本协议，不提供保密性 |
| 单向摘要 | MD5、SHA 系列 | 不可逆 | 无 | 完整性校验、密码存储 |

| 非对称加密 | RSA、ECC | 可逆 | 公私钥对 | 密钥分发、签名与身份认证 |

## [后量子密码学简介](./post-quantum-cryptography.md)

后量子密码学（Post-Quantum Cryptography, PQC）研究抵抗量子计算机攻击的密码算法。量子计算对现有公钥密码体系的威胁（Shor 算法、Grover 算法的影响）、格基/哈希基/编码基/多变量/超奇异椭圆曲线同源五条技术路线、NIST 后量子密码算法标准化进程，以及 TLS、区块链、物联网等领域的应用前景与迁移策略。

| 技术路线 | 数学基础 | 密钥封装机制(KEM) | 数字签名 | 密钥交换 | 加密方案 |
|---------|---------|-----------------|---------|---------|---------|
| 格基密码学 | 格上最短向量问题(SVP)、最近向量问题(CVP)、学习错误(LWE)问题 | CRYSTALS-Kyber | CRYSTALS-Dilithium、FALCON、SPHINCS+ | CRYSTALS-Kyber | Kyber-Encrypt |
| 哈希基密码学 | 哈希函数的抗碰撞性、单向性 | - | SPHINCS+、XMSS、MSS、WOTS+ | - | - |
| 编码基密码学 | 线性纠错码解码难度问题 | Classic McEliece | - | - | - |
| 多变量密码学 | 有限域上多变量多项式方程组求解难度(MQ问题) | - | Rainbow、GeMSS | - | - |
| 超奇异椭圆曲线同源密码学 | 超奇异椭圆曲线间同源的计算与逆向难度 | SIKE(已撤回) | - | SIDH、CSIDH | - |
