后量子密码学（Post-Quantum Cryptography, PQC）研究能够抵抗量子计算机攻击的密码算法。传统公钥密码体系的安全性建立在大整数分解、离散对数这类问题上，而这类问题在量子计算机上存在多项式时间的求解算法，因此 PQC 的核心工作是换一批底层困难问题，重建公钥密码。

量子计算对密码体系的威胁

量子计算对密码学的威胁集中在两个算法上：Shor 算法打公钥密码，Grover 算法削弱对称密码的有效密钥强度。

Shor 算法

Shor 算法由彼得·肖尔（Peter Shor）于1994年提出，是第一个能够在多项式时间内解决大整数分解和离散对数问题的量子算法。

技术原理：

  • 利用量子并行性同时尝试多个可能的解
  • 通过量子傅里叶变换将周期性问题转换为可测量的量子状态
  • 能够在 O((log N)^3) 时间内分解大整数 N

威胁范围：

  • RSA 算法（基于大整数分解问题）
  • ECC 算法（基于椭圆曲线离散对数问题）
  • DSA、DH 等基于离散对数问题的算法

影响程度：

  • TLS 证书、数字签名、密钥交换等依赖上述算法的机制全部失效
  • 目前广泛使用的 2048 位 RSA 密钥预计可在 24 小时内被破解

Grover 算法

Grover 算法由洛夫·格罗弗（Lov Grover）于1996年提出，是一种量子搜索算法，能够加速无序数据库的搜索过程。

技术原理：

  • 利用量子叠加态同时搜索所有可能的解
  • 通过振幅放大技术提高找到正确解的概率
  • 能够将搜索复杂度从 O(N) 降低到 O(√N)

威胁范围：

  • 所有对称加密算法（如 AES、ChaCha20）
  • 哈希函数的碰撞查找
  • 暴力破解攻击

影响程度：

  • 将对称加密的密钥强度有效减半（如 AES-256 的安全强度降至约 AES-128 水平）
  • 需将密钥长度增加一倍以维持相同的安全级别

后量子密码学的技术路线

目前有五条主要技术路线：格基、哈希基、编码基、多变量、同源。每条路线各自依赖一类被认为难以被量子计算机高效求解的数学问题。

格基密码学（Lattice-based Cryptography）

格基密码学基于格（Lattice）这一数学结构中的计算难题。自 1996 年 Ajtai 提出第一个基于格的抗量子密码方案以来，格基密码学已发展成为后量子密码学中成熟度和落地度最高的一条路线。

格的基本概念与数学定义

格是 n 维欧几里得空间中，由一组线性无关向量（称为基）的所有整数线性组合构成的离散点集。

L = { a₁v₁ + a₂v₂ + ... + aₙvₙ | aᵢ ∈ ℤ }

其中：

  • v₁, v₂, ..., vₙ 是 n 维空间中的一组线性无关向量，称为格的基
  • a₁, a₂, ..., aₙ 是整数系数
  • 格的维数是基向量的个数 n

格的几何表示：

  • 在 2 维空间中，格可以看作由基向量生成的网格点集
  • 在高维空间中，格的结构变得极其复杂，计算难度呈指数增长

格中的核心困难问题

格基密码学的安全性基于格中的两个核心困难问题，以及由它们派生的 LWE。

最短向量问题（Shortest Vector Problem, SVP）

问题描述：给定格 L，找到 L 中长度最短的非零向量。

SVP(L) = min{ ||v|| | v ∈ L, v ≠ 0 }
  • 近似 SVP：在实际应用中，通常考虑近似版本的 SVP，即找到长度不超过 λ 倍最短向量的向量（λ ≥ 1）
  • 计算复杂度：对于高维格（n > 100），精确求解 SVP 是 NP 难的，近似求解也需要指数时间
最近向量问题（Closest Vector Problem, CVP）

问题描述：给定格 L 和一个目标向量 t，找到 L 中距离 t 最近的向量。

CVP(L, t) = argmin{ ||t - v|| | v ∈ L }
  • 近似 CVP：同样，实际应用中主要考虑近似版本
  • 与 SVP 的关系：CVP 至少与 SVP 一样难，在某些情况下甚至更难
学习错误问题（Learning With Errors, LWE）

LWE 是格基密码学中最常用的计算难题，由 Regev 于 2005 年提出，可归约到格中的最坏情况困难问题。

问题描述：给定 m 个样本 (aᵢ, bᵢ)，其中 bᵢ = aᵢ·s + eᵢ，

  • aᵢ 是随机向量
  • s 是秘密向量
  • eᵢ 是随机误差

任务是恢复秘密向量 s。

LWE 问题的变体环学习错误问题（Ring-LWE, RLWE）通过利用环结构大幅提高了效率，是现代格基密码算法的基础。

格基密码学的主要算法

CRYSTALS-Kyber（密钥封装机制）

CRYSTALS-Kyber 是 NIST 选定的后量子密钥封装机制标准，基于 Ring-LWE 问题。

设计目标：提供与传统公钥算法相当的性能。

核心技术：

  • 采用多项式环上的 LWE 问题（Ring-LWE）
  • 使用模运算和错误注入
  • 支持不同安全级别参数（Kyber-512/768/1024）

性能指标：

  • 公钥大小：800-1568 字节
  • 密文大小：768-1568 字节
  • 密钥封装时间：约 1.5ms（软件实现）
CRYSTALS-Dilithium（数字签名）

CRYSTALS-Dilithium 是 NIST 选定的后量子数字签名标准，基于格中的短整数解问题（SIS）。

设计目标：提供高强度的安全性和合理的性能。

核心技术：

  • 采用模块格（Module Lattice）结构
  • 使用拒绝采样技术确保签名的正确性
  • 支持不同安全级别参数（Dilithium-2/3/5）

性能指标：

  • 公钥大小：1.3-2.5KB
  • 私钥大小：2.5-4.0KB
  • 签名大小：2.4-4.5KB
  • 签名时间：约 12ms；验证时间：约 2ms
FALCON（数字签名）

FALCON 是 NIST 选定的后量子数字签名标准，基于 NTRU 格和快速傅里叶变换。

设计目标：提供小尺寸签名。

核心技术：

  • 采用 NTRU 格结构
  • 使用快速傅里叶变换加速计算
  • 采用高斯采样生成短向量

性能指标：

  • 公钥大小：897-1793 字节
  • 私钥大小：1281-2305 字节
  • 签名大小：401-666 字节（远小于 Dilithium）
  • 签名和验证速度快于 Dilithium
NTRU（密钥交换和加密）

NTRU 是最早的实用格基密码算法之一，基于多项式环上的卷积运算。

  • 设计历史：1996 年由 Hoffstein、Pipher 和 Silverman 提出
  • 核心技术：使用小系数多项式和模运算
  • 特点：计算效率高，密钥尺寸小

格基密码学的优势

相比其他后量子密码技术路线，格基密码学有以下几点优势。

  1. 可证明的安全性：

    • 安全性可归约到格中最坏情况的困难问题
    • 提供了最严格的安全性保证

  2. 优异的性能：

    • 计算效率接近传统公钥算法（RSA/ECC）
    • 密钥和密文尺寸合理

  3. 灵活的密码原语支持：

    • 可构建几乎所有密码原语：加密、签名、密钥交换、身份认证等
    • 支持属性基加密、全同态加密等高级密码功能

  4. 并行计算能力：

    • 算法设计天然支持并行计算
    • 可充分利用现代 CPU/GPU 的并行处理能力

  5. 硬件友好性：

    • 主要运算为加法和乘法，适合硬件加速
    • 对功耗和资源的要求相对较低，适合嵌入式设备

格基密码学的挑战

  1. 实现复杂度：

    • 算法设计涉及复杂的数学概念
    • 高效实现需要深入理解格结构和优化技术

  2. 参数选择：

    • 需要仔细选择参数以平衡安全性和性能
    • 参数错误可能导致安全漏洞

  3. 侧信道攻击防护：

    • 格基密码算法容易受到侧信道攻击
    • 需要额外的防护措施（如掩码技术）

  4. 标准化进程：

    • 虽然 NIST 已选定标准算法，但广泛部署仍需时间
    • 需要与现有密码系统兼容

格基密码学的应用前景

  • TLS/SSL 协议：替换现有的 RSA/ECC 密钥交换和签名机制
  • 区块链技术：确保加密货币的长期安全
  • 物联网设备：提供高效的轻量级加密方案
  • 云计算：支持安全的同态加密和多方计算
  • 量子通信：作为量子密钥分发的补充，提供后量子安全保障

哈希基密码学（Hash-based Cryptography）

哈希基密码学基于密码学哈希函数的安全性，是最早被提出、理论基础也最成熟的一条技术路线。它的核心思想是利用哈希函数的抗碰撞性、单向性构建密码原语，主要产物是数字签名方案。

历史与发展

哈希基密码学的发展可以追溯到 20 世纪 70 年代末。

  • 1979 年：Ralph Merkle 提出了 Merkle 签名方案（MSS），这是第一个基于哈希函数的数字签名方案
  • 1981 年：Robert Winternitz 提出了 Winternitz 一次性签名方案（WOTS），改进了 Merkle 方案的效率
  • 1990 年代：出现了多种基于哈希的签名方案变体，如 Lamport-Diffie 签名方案
  • 2000 年代：提出了可扩展的哈希基签名方案，如 XMSS（eXtended Merkle Signature Scheme）
  • 2015 年：SPHINCS 方案提出，解决了状态管理问题
  • 2019 年：SPHINCS+ 作为 SPHINCS 的改进版被提出，并被 NIST 选定为后量子签名标准

核心概念与数学基础

哈希基密码学的安全性基于密码学哈希函数的以下特性。

哈希函数的密码学特性
  • 单向性：给定哈希值 h，很难找到原像 x 使得 H(x)=h
  • 抗碰撞性：很难找到两个不同的输入 x≠y，使得 H(x)=H(y)
  • 抗第二原像性：给定 x，很难找到 y≠x 使得 H(x)=H(y)
  • 伪随机性：哈希函数的输出看起来是随机的
一次性签名方案（One-Time Signature, OTS）

哈希基密码学的基本构建块是一次性签名方案，它允许用户对最多一条消息进行安全签名。主要包括：

  • Lamport 签名：使用成对的随机密钥，每条消息位对应一对密钥
  • Winternitz 签名（WOTS）：改进的一次性签名方案，减少了密钥数量
Merkle 树结构

为了将一次性签名方案扩展为可多次使用的签名方案，哈希基密码学使用 Merkle 树（也称为哈希树）结构：

       root
      /    \
     /      \
    h1      h2
   / \     / \
  h11 h12 h21 h22
 / \ / \ / \ / \
x1 x2 x3 x4 x5 x6 x7 x8
  • 叶节点：一次性签名密钥对
  • 内部节点：子节点的哈希值
  • 根节点：整个树的哈希值，作为公钥

主要构建块

Winternitz 一次性签名方案（WOTS）

WOTS 是哈希基密码学中最常用的一次性签名方案之一，它通过使用多进制表示减少了密钥数量。

工作原理：

  1. 密钥生成：

    • 选择安全参数 w（通常为 4 或 16）
    • 生成 n 个随机种子 sk_1, sk_2, ..., sk_n 作为私钥
    • 计算公钥 pk_i = H^w(sk_i)，其中 H^w 表示对 sk_i 进行 w 次哈希

  2. 签名生成：

    • 将消息哈希为 n 个 w 进制数字 m_1, m_2, ..., m_n
    • 计算签名 sig_i = H^{w - m_i}(sk_i)

  3. 签名验证：

    • 计算 H^{m_i}(sig_i) 并验证是否等于 pk_i

优势：

  • 密钥和签名尺寸比 Lamport 签名小
  • 实现简单，安全性基于哈希函数的抗碰撞性
Merkle 签名方案（MSS）

MSS 将 WOTS 等一次性签名方案与 Merkle 树结合，实现了可多次使用的签名方案。

工作原理：

  1. 密钥生成：

    • 生成 k 对 WOTS 密钥对
    • 将这些密钥对的公钥作为 Merkle 树的叶节点
    • 计算 Merkle 树的根作为 MSS 的公钥

  2. 签名生成：

    • 选择一个未使用的 WOTS 密钥对
    • 用该密钥对生成消息签名
    • 生成该叶节点到根节点的认证路径
    • 将 WOTS 签名和认证路径作为 MSS 签名

  3. 签名验证：

    • 验证 WOTS 签名的有效性
    • 使用认证路径验证 WOTS 公钥是否在 Merkle 树中

限制：

  • 签名次数受限于 Merkle 树的叶节点数量
  • 需要维护状态信息以跟踪已使用的密钥对

主要算法

SPHINCS+（Stateless Hash-Based Signatures）

SPHINCS+ 是 NIST 选定的后量子数字签名标准，是一种无状态的哈希基签名方案，解决了 MSS 等方案需要状态管理的问题。

核心设计：

  • 无状态设计：不需要维护已使用签名的状态信息
  • 层次化结构：使用树的树（Tree of Trees）结构
  • 安全参数：支持不同安全级别（SPHINCS+-SHA2-128s/128f/192s/192f/256s/256f）

工作原理：

  1. 密钥生成：

    • 生成主密钥种子
    • 从主种子派生出多层 Merkle 树结构
    • 最上层树的根作为公钥

  2. 签名生成：

    • 使用伪随机数生成器从主私钥派生出临时密钥
    • 生成一次性签名和多层认证路径
    • 组合成最终签名

  3. 签名验证：

    • 验证一次性签名
    • 验证所有层的认证路径
    • 确认最终哈希值与公钥匹配

性能指标：

安全级别公钥大小私钥大小签名大小签名时间验证时间
SPHINCS+-SHA2-128s32字节64字节7,856字节~10ms~5ms
SPHINCS+-SHA2-128f32字节64字节31,088字节~40ms~20ms
SPHINCS+-SHA2-256s64字节128字节17,088字节~20ms~10ms
SPHINCS+-SHA2-256f64字节128字节67,408字节~80ms~40ms
XMSS（eXtended Merkle Signature Scheme）

XMSS 是 MSS 的扩展，支持无限次签名，但需要维护状态信息。

核心特点：

  • 使用迭代哈希链生成多个 Merkle 树
  • 支持向前安全（Forward Secrecy）
  • 每个签名消耗一个叶节点

应用场景：

  • 需要无限次签名但可以维护状态的应用
  • 区块链技术中的交易签名

安全性分析

  1. 抗量子性：

    • 目前没有已知的量子算法可以有效攻击基于哈希的密码方案
    • Grover 算法只能将碰撞搜索复杂度从 O(2^n) 降低到 O(2^{n/2})，可以通过增加哈希长度来应对

  2. 可证明安全性：

    • 大多数哈希基方案的安全性可以归约到哈希函数的基本特性
    • 安全性证明相对简单且可靠

  3. 长期安全性：

    • 只要底层哈希函数保持安全，哈希基方案就保持安全
    • 可以通过更换底层哈希函数来应对未来的威胁

性能与效率分析

  1. 计算效率：

    • 签名和验证主要依赖哈希运算，计算复杂度低
    • 适合资源受限设备

  2. 存储需求：

    • 公钥尺寸小（通常为 32-64 字节）
    • 签名尺寸较大（通常为几 KB 到几十 KB）

  3. 带宽需求：

    • 较大的签名尺寸会增加带宽消耗
    • 不适合带宽受限的应用场景

应用场景

哈希基密码学主要用于数字签名领域，适合以下应用场景。

  1. 长期存储安全：

    • 数字文档的长期归档
    • 证书颁发机构的根证书

  2. 区块链技术：

    • 交易签名
    • 区块头签名
    • 智能合约验证

  3. 安全启动：

    • 固件签名
    • 硬件设备的安全启动

  4. 资源受限设备：

    • 物联网设备
    • 传感器节点

优势与挑战

优势：

  1. 成熟的理论基础：

    • 研究历史悠久，安全性分析深入
    • 可证明安全性强

  2. 抗量子性：

    • 不受量子算法威胁
    • 长期安全性有保障

  3. 实现简单：

    • 主要依赖哈希函数，实现复杂度低
    • 易于在各种平台上部署

  4. 灵活性：

    • 可以与不同的哈希函数结合使用
    • 支持多种安全级别

挑战：

  1. 签名尺寸较大：

    • 限制了在带宽受限场景的应用
    • 增加了存储和传输成本

  2. 状态管理（对于有状态方案）：

    • 需要跟踪已使用的签名
    • 状态丢失可能导致安全问题

  3. 验证速度相对较慢：

    • 多层认证路径验证增加了计算开销
    • 不适合高频交易场景

  4. 密钥管理：

    • 无状态方案的私钥尺寸较大
    • 需要安全的密钥存储机制

标准化进展

  1. NIST 后量子密码标准化：

    • SPHINCS+ 被选定为标准算法
    • 作为数字签名方案的重要组成部分

  2. IETF 标准：

    • 正在制定哈希基签名的互联网标准
    • 包括 XMSS 和 SPHINCS+ 的应用规范

  3. 行业应用：

    • 部分区块链项目已开始采用哈希基签名
    • 安全芯片厂商正在集成哈希基密码算法

编码基密码学（Code-based Cryptography）

编码基密码学基于纠错码理论，是最早提出、理论基础也最牢固的一条技术路线。其核心思想是利用线性纠错码的解码难度构建密码原语，主要产物是公钥加密和密钥封装机制。

历史与发展

编码基密码学的发展可以追溯到 20 世纪 70 年代末。

  • 1978 年：Robert McEliece 提出了第一个基于纠错码的公钥加密方案，即 McEliece 密码系统
  • 1986 年：Hans Niederreiter 提出了一个等价于 McEliece 方案的变体，称为 Niederreiter 算法
  • 1990 年代：出现了多种基于不同纠错码的密码方案，但大多被证明存在安全缺陷
  • 2000 年代：研究重点转向提高 McEliece 方案的效率和安全性
  • 2017 年：Classic McEliece 方案作为 McEliece 的改进版被提交到 NIST 后量子密码标准化过程
  • 2023 年：Classic McEliece 被 NIST 选定为后量子密码标准算法

核心概念与数学基础

编码基密码学的安全性基于线性纠错码的数学理论，特别是解码问题的计算难度。

线性纠错码的基本概念

线性纠错码是一种将信息位映射到更长的码字的数学结构，用于在噪声信道中传输数据时检测和纠正错误。

  • 信息位：需要传输的原始数据
  • 校验位：附加的冗余位，用于错误检测和纠正
  • 码字：信息位和校验位的组合
  • 码长：码字的总位数（n）
  • 维数：信息位的位数（k）
  • 最小距离：任意两个不同码字之间的最小汉明距离，决定了码的纠错能力
生成矩阵与校验矩阵

线性纠错码可以用两种矩阵表示。

生成矩阵 G：

  • 尺寸为 k×n 的矩阵
  • 将 k 位信息向量 m 映射到 n 位码字 c：c = m·G

校验矩阵 H：

  • 尺寸为 (n-k)×n 的矩阵
  • 满足 G·H^T = 0（零矩阵）
  • 用于检测错误：对于有效的码字 c，c·H^T = 0
核心困难问题

一般解码问题（General Decoding Problem, GDP）：

  • 给定一个校验矩阵 H 和一个接收向量 r，找到一个码字 c 使得汉明重量 w(r - c) 最小
  • 该问题是 NP 难的，即使对于量子计算机也是如此

有界距离解码问题（Bounded Distance Decoding, BDD）：

  • 给定一个校验矩阵 H、一个接收向量 r 和一个距离 t，找到一个码字 c 使得 w(r - c) ≤ t
  • 这是 GDP 的一个特例，同样是 NP 难的

McEliece 密码系统

McEliece 密码系统是编码基密码学中最具代表性的算法，基于 Goppa 码的解码难度。

Goppa 码简介

Goppa 码是一类具有良好代数结构的线性纠错码，具有以下特点：

  • 可以构造具有较大最小距离的码
  • 存在有效的解码算法（Peterson-Gorenstein-Zierler 算法）
  • 解码复杂度与码长成多项式关系
McEliece 方案的工作原理

McEliece 密码系统的核心是将一个结构化的 Goppa 码伪装成一个随机线性码，利用随机码解码的困难性来保证安全性。

  1. 密钥生成

  • 选择参数：

    • n：码长
    • k：维数
    • t：纠错能力

  • 构造 Goppa 码：

    • 选择一个不可约多项式 g(x) 在有限域 GF(2^m) 上
    • 构造 Goppa 码的生成矩阵 G

  • 伪装码结构：

    • 选择一个 k×k 的随机可逆矩阵 S（scrambler matrix）
    • 选择一个 n×n 的随机置换矩阵 P（permutation matrix）
    • 计算公钥生成矩阵：G' = S·G·P

  • 输出：

    • 公钥：(G', t)
    • 私钥：(S, G, P)
  1. 加密
  • 对于消息 m（k 位）
  • 生成一个随机错误向量 e，汉明重量为 t
  • 计算密文：c = m·G' + e
  1. 解密
  • 计算 c·P^{-1} = m·S·G + e·P^{-1}
  • 使用私钥中的 Goppa 码 G 和有效的解码算法恢复 m·S
  • 计算 m = (m·S)·S^{-1}
Niederreiter 算法

Niederreiter 算法是 McEliece 方案的一个变体，基于错误向量而不是信息向量进行加密：

  • 密钥生成：与 McEliece 类似，但使用校验矩阵 H 而不是生成矩阵 G
  • 加密：对错误向量 e 进行加密，而不是信息向量 m
  • 解密：从密文中恢复错误向量 e，然后提取信息

Niederreiter 算法与 McEliece 算法在数学上是等价的，但在某些情况下具有更高的效率。

Classic McEliece 方案

Classic McEliece 是 McEliece 方案的改进版，针对效率和安全性进行了优化，被 NIST 选定为后量子密码标准。

主要改进
  • 参数优化：选择了更安全和高效的参数组合
  • 实现优化：使用更高效的编码和解码算法
  • 安全性增强：针对已知攻击进行了加固

  • 公钥尺寸大：是编码基密码学的主要缺点

抗量子性
  • 量子算法抗性：目前没有已知的量子算法可以有效解决一般线性码的解码问题
  • Grover 算法影响：Grover 算法只能将解码问题的复杂度从 O(2^t) 降低到 O(2^{t/2})，可以通过增加 t 值来应对
已知攻击与安全边界

编码基密码学面临的主要攻击包括：

  • 结构攻击：试图利用公钥中可能泄露的码结构信息
  • 信息集解码（ISD）攻击：通过猜测信息位的子集来解码
  • 区分攻击：试图区分结构化码和随机码
安全证明
  • 可证明安全性：McEliece 方案的安全性可以归约到一般解码问题的难度
  • 后量子安全性：即使在量子计算机存在的情况下，解码问题仍然是困难的

性能与效率分析

计算效率
  • 加密：非常快，主要是矩阵-向量乘法
  • 解密：相对较慢，需要执行解码算法
  • 密钥生成：一次性操作，复杂度较高
存储需求
  • 公钥：非常大（数百 KB 到数 MB），这是编码基密码学的主要缺点
  • 私钥：相对较小（几 KB）
  • 密文：与消息长度相当，非常紧凑
带宽需求
  • 公钥传输：需要较大带宽
  • 密文传输：带宽需求小，适合数据传输

应用场景

尽管编码基密码学存在公钥尺寸大的缺点，但在某些特定场景下仍有优势。

  1. 数据加密：

    • 适合一次性加密大量数据
    • 密文尺寸小，节省带宽

  2. 密钥封装：

    • 用于建立安全通信的会话密钥
    • 与对称加密结合使用

  3. 存储加密：

    • 用于加密存储在数据库或文件系统中的数据
    • 不需要频繁传输公钥

  4. 物联网设备：

    • 适合计算资源有限但存储资源相对充足的设备
    • 加密操作速度快，适合实时应用

  5. 后量子 TLS：

    • 作为密钥交换的备选方案
    • 与其他后量子算法结合使用

优势：

  1. 成熟的理论基础：

    • 基于已研究数十年的纠错码理论
    • 数学基础牢固，安全性分析深入

  2. 抗量子性：

    • 解码问题对量子算法具有抗性
    • 长期安全性有保障

  3. 加密速度快：

    • 加密操作非常高效
    • 适合高性能应用

  4. 密文尺寸小：

    • 节省带宽和存储
    • 适合数据传输

  5. 可证明安全性：

    • 安全性可以归约到公认的困难问题
    • 没有已知的多项式时间攻击

挑战：

  1. 公钥尺寸过大：

    • 是编码基密码学的主要缺点
    • 限制了在带宽受限场景的应用
    • 增加了存储和传输成本

  2. 密钥生成复杂：

    • 需要生成大尺寸的随机矩阵
    • 计算开销较高

  3. 缺乏签名方案：

    • 目前没有高效的基于编码的数字签名方案
    • 主要应用于加密领域

  4. 实现复杂度：

    • 需要高效实现大尺寸矩阵运算
    • 对硬件资源要求较高

标准化进展

  1. NIST 后量子密码标准化：

    • Classic McEliece 被选定标准算法
    • 作为密钥封装机制的重要组成部分

  2. IETF 标准：

    • 正在制定基于编码的后量子密码算法的应用规范
    • 包括在 TLS 协议中的应用

  3. 行业应用：

    • 安全芯片厂商正在评估编码基密码算法

  1. 减小公钥尺寸：

    • 针对新型攻击进行加固
    • 研究抗量子的纠错码

多变量密码学（Multivariate Cryptography）

多变量密码学基于有限域上多变量多项式方程组的求解难度。其核心思想是利用求解随机多变量多项式方程组的计算困难性构建密码原语，主要产物是数字签名方案。

历史与发展

多变量密码学的发展可以追溯到 20 世纪 80 年代。

  • 1985 年：Shamir 首次提出基于多变量二次方程的签名方案（Oil and Vinegar 方案）
  • 1990 年代：出现了多种多变量密码方案，如 SFLASH、QUARTZ 等
  • 2005 年：提出了 Rainbow 签名方案，成为多变量密码学的代表性算法
  • 2007 年：SFLASH 算法被成功破解，暴露了多变量密码学的安全性挑战
  • 2017 年：多个多变量密码方案被提交到 NIST 后量子密码标准化过程
  • 2020 年代：研究重点转向提高多变量密码方案的安全性和效率

核心概念与数学基础

多变量密码学的安全性基于有限域上多变量多项式方程组的求解难度，这是一个经典的 NP 难问题。

基本概念

多变量多项式方程组：

  • 由多个未知数和多个多项式方程组成的系统
  • 形式：{f₁(x₁, x₂, ..., xₙ) = 0, f₂(x₁, x₂, ..., xₙ) = 0, ..., fₘ(x₁, x₂, ..., xₙ) = 0}

有限域：

  • 具有有限个元素的域，通常表示为 GF(q)，其中 q 是素数的幂
  • 多变量密码学主要使用 GF(2^k) 等二进制有限域
核心困难问题

多变量二次方程组问题（MQ 问题）：

  • 给定有限域 GF(q) 上的 m 个 n 元二次多项式，找到一个 n 维向量使得所有多项式都等于 0
  • 该问题是 NP 难的，即使对于量子计算机也是如此

随机多变量二次方程组问题（Random MQ 问题）：

  • MQ 问题的一个特例，其中多项式是随机选择的
  • 被认为是 NP 难的，没有已知的高效算法可以解决
隐藏结构的思想

多变量密码学的关键设计思想是隐藏结构：

  1. 构造一个结构化的、容易求解的方程组
  2. 通过可逆变换隐藏这个结构
  3. 公钥是变换后的方程组，私钥是变换信息和原始结构
  4. 签名/解密利用私钥恢复原始结构，从而高效求解

主要算法

多变量密码学主要用于构建数字签名方案，以下是几个代表性算法。

Oil and Vinegar（Ov）方案

Oil and Vinegar 是 Shamir 于 1985 年提出的第一个多变量签名方案，奠定了多变量密码学的基础。

基本思想：

  • 将变量分为两组："oil" 变量和 "vinegar" 变量
  • 构造只包含 vinegar 变量的二次方程，形式简单易解
  • 通过线性变换隐藏变量的分组结构

工作原理：

  1. 密钥生成：

    • 选择 n 个 vinegar 变量和 m 个 oil 变量（通常 n = m）
    • 构造 m 个二次多项式，只包含 vinegar 变量
    • 应用线性变换隐藏变量结构

  2. 签名生成：

    • 选择随机的 vinegar 变量值
    • 计算对应的 oil 变量值
    • 应用逆变换生成签名

  3. 签名验证：

    • 检查签名是否满足公钥多项式方程组

安全性：

  • 原始 Ov 方案在 1998 年被成功攻击
  • 主要问题是变量分组结构可能通过密码分析恢复
Rainbow 方案

Rainbow 是 Ding 等人于 2005 年提出的多层 Oil and Vinegar 方案，是多变量密码学中应用最广的算法之一。

基本思想：

  • 使用多个 Oil and Vinegar 层组成 "彩虹" 结构
  • 每层有自己的 oil 和 vinegar 变量
  • 层与层之间通过变量共享连接

工作原理：

  1. 密钥生成：

    • 选择参数：层数 v，每层的 oil 变量数 o₁, o₂, ..., oᵥ
    • 构造 v 层 Oil and Vinegar 结构
    • 应用线性变换隐藏结构

  2. 签名生成：

    • 从最上层开始，逐层计算变量值
    • 利用私钥的结构信息高效求解

  3. 签名验证：

    • 检查签名是否满足公钥多项式方程组

SFLASH 算法

SFLASH 是一种基于多变量密码学的数字签名算法，曾经被欧盟选中作为电子身份证的加密标准。

特点：

  • 签名尺寸小（36 字节）
  • 签名生成和验证速度快
  • 公钥尺寸相对较小（~15KB）

安全性：

  • 2007 年被成功破解
  • 攻击利用了算法中的特殊结构
  • 暴露了多变量密码学在参数选择上的安全挑战
QUARTZ 算法

QUARTZ 是一种基于 SFLASH 的多变量签名算法，专为低资源设备设计。

特点：

  • 签名尺寸小（128 位）
  • 公钥尺寸适中（~12KB）
  • 设计用于智能卡等资源受限设备

安全性：

  • 由于与 SFLASH 的相似性，其安全性受到质疑
  • 未被广泛采用

安全性分析

抗量子性
  • 量子算法抗性：目前没有已知的量子算法可以有效解决 MQ 问题
  • Grover 算法影响：Grover 算法只能提供二次加速，影响有限
  • 长期安全性：被认为具有良好的后量子安全性
已知攻击

多变量密码学面临的主要攻击包括：

  1. 结构攻击：

    • 试图恢复公钥中隐藏的结构信息
    • 针对 Oil and Vinegar 等方案的主要攻击方式

  2. 秩攻击：

    • 利用多项式方程组的秩性质
    • 适用于某些特定的多变量方案

  3. 差分攻击：

    • 分析变量差分对多项式输出的影响
    • 已成功应用于破解 SFLASH 等方案

  4. 线性化攻击：

    • 将二次方程组转化为线性方程组求解
    • 对于某些特殊结构的方程组有效
安全证明
  • 可证明安全性：大多数多变量密码方案缺乏严格的安全证明
  • 启发式安全性：安全性主要基于经验和已知攻击的抗性
  • 参数选择：安全参数的选择需要谨慎，以抵抗已知攻击

性能与效率分析

计算效率
  • 签名生成：非常快，主要是多项式求值和简单的代数运算
  • 签名验证：相对较快，但比签名生成慢（需要验证多个方程）
  • 密钥生成：一次性操作，复杂度适中
存储需求
  • 公钥：中等大小（几 KB 到几十 KB）
  • 私钥：相对较小（几 KB）
  • 签名：非常小（几十字节），这是多变量密码学的主要优势之一
带宽需求
  • 公钥传输：带宽需求适中
  • 签名传输：带宽需求小，适合资源受限环境

应用场景

多变量密码学主要用于数字签名领域，在以下场景具有优势。

  1. 资源受限设备：

    • 智能卡、RFID 标签等计算能力有限的设备
    • 签名生成速度快，适合实时应用

  2. 大规模部署：

    • 需要处理大量签名的系统
    • 如电子投票、供应链管理等

  3. 低带宽环境：

    • 签名尺寸小，节省传输带宽
    • 适合物联网等带宽受限场景

  4. 后量子安全升级：

    • 作为传统签名算法的后量子替代方案
    • 可与其他后量子算法结合使用

  5. 区块链技术：

    • 小尺寸签名可以减少区块链存储需求
    • 签名生成速度快，适合高频交易场景

优势与挑战

优势：

  1. 签名性能优异：

    • 签名生成速度快，适合资源受限设备
    • 签名尺寸小，节省存储和带宽

超奇异椭圆曲线同源密码学（Isogeny-based Cryptography）

超奇异椭圆曲线同源密码学基于椭圆曲线间同源问题的难度。其核心思想是利用椭圆曲线间同源的计算和逆向难度构建密码原语，主要产物是密钥交换和密钥封装机制。

历史与发展

超奇异椭圆曲线同源密码学的发展可以追溯到 21 世纪初。

  • 2006 年：Couveignes 首次提出基于椭圆曲线同源的密码方案
  • 2010 年：Rostovtsev 和 Stolbunov 独立提出了类似的方案
  • 2011 年：Jao 和 De Feo 提出了基于超奇异椭圆曲线同源的密钥交换协议（SIDH）
  • 2016 年：基于 SIDH 的密钥封装机制（SIKE）被提出
  • 2017 年：SIKE 被提交到 NIST 后量子密码标准化过程
  • 2022 年：SIKE 算法被成功破解，暴露了同源密码学的安全性挑战
  • 2020 年代：研究重点转向更安全的同源密码方案，如 CSIDH

核心概念与数学基础

椭圆曲线基础

椭圆曲线：

  • 定义在有限域 GF(p) 上的曲线，满足方程：y² = x³ + ax + b（Weierstrass 形式）
  • 曲线上的点构成一个加法群

超奇异椭圆曲线：

  • 椭圆曲线的一种特殊类型，具有额外的代数结构
  • 其点数满足特殊的数学性质
  • 超奇异椭圆曲线的数量远少于普通椭圆曲线
同源的定义

同源（Isogeny）：

  • 两个椭圆曲线 E 和 E' 之间的有理映射 φ: E → E'
  • 保持群结构：φ(P + Q) = φ(P) + φ(Q) 对所有 P, Q ∈ E 成立
  • 是非零映射（即不是常数映射）

同源的度数：

  • 同源映射的度数 deg(φ) 表示映射的复杂度
  • 对于超奇异椭圆曲线，同源的度数通常是小素数的幂
同源图

同源图：

  • 由超奇异椭圆曲线作为顶点，同源作为边构成的图
  • 图中的路径代表一系列同源的组合
  • 同源密码学利用同源图的遍历困难性来构建密码系统
核心困难问题

超奇异同源路径问题（SSPP）：

  • 给定两条超奇异椭圆曲线 E 和 E'，找到它们之间的同源路径
  • 被认为是困难的，目前没有已知的高效算法

超奇异同源离散对数问题（SSIDLP）：

  • 给定同源 φ 和点 φ(P)，找到整数 k 使得 φ = [k]
  • 是 SIDH/SIKE 等算法的安全性基础

主要算法

超奇异椭圆曲线同源密码学主要用于密钥交换和密钥封装，以下是几个代表性算法。

SIDH（Supersingular Isogeny Diffie-Hellman）

SIDH 是 Jao 和 De Feo 于 2011 年提出的基于超奇异椭圆曲线同源的密钥交换协议。

基本思想：

  • 双方各自选择一条超奇异椭圆曲线
  • 通过交换同源信息构建共享密钥
  • 安全性基于超奇异同源路径问题的困难性

工作原理：

  1. 密钥生成：

    • 选择有限域 GF(p²) 上的超奇异椭圆曲线 E
    • 选择两个不同的素数 ℓ_A 和 ℓ_B
    • 生成 Alice 的私钥 a 和 Bob 的私钥 b

  2. 密钥交换：

    • Alice 计算度数为 ℓ_A^e 的同源 φ_A，得到曲线 E_A = φ_A(E)
    • Bob 计算度数为 ℓ_B^e 的同源 φ_B，得到曲线 E_B = φ_B(E)
    • Alice 和 Bob 交换 E_A 和 E_B
    • Alice 计算 E_AB = φ_A^{-1}(E_B)
    • Bob 计算 E_BA = φ_B^{-1}(E_A)
    • E_AB 和 E_BA 是同构的，共享密钥基于此曲线生成

安全性：

  • 2022 年，SIDH 的变种 SIKE 被破解
  • 攻击利用了同源图的特殊结构
  • 原始 SIDH 的安全性也受到质疑
SIKE（Supersingular Isogeny Key Encapsulation）

SIKE 是基于 SIDH 的密钥封装机制，曾被提交到 NIST 后量子密码标准化过程。

基本思想：

  • 将 SIDH 密钥交换协议转换为密钥封装机制
  • 用于在不安全信道上安全地传输对称密钥

工作原理：

  1. 密钥生成：

    • 生成公钥和私钥对，类似于 SIDH

  2. 封装：

    • 使用接收方的公钥生成一个随机对称密钥
    • 计算密文，包含封装信息

  3. 解封装：

    • 使用接收方的私钥从密文中恢复对称密钥

  • 2022 年，SIKE 被成功破解
  • 攻击基于 Kani 的可约性判据，利用协议中交换的挠点像
  • NIST 随后撤回了 SIKE 的标准化考虑
CSIDH（Commutative Supersingular Isogeny Diffie-Hellman）

CSIDH 是一种基于交换同源的密钥交换协议，由 Castryck、Lange、Martindale、Panny 和 Renes 于 2018 年提出。

基本思想：

  • 使用交换的同源操作
  • 每个用户的私钥是一个小素数的乘积
  • 安全性基于超奇异同源路径问题的困难性

工作原理：

  1. 密钥生成：

    • 选择一条超奇异椭圆曲线 E
    • 选择一个由小素数组成的私钥向量
    • 计算对应的同源，得到公钥曲线 E'

  2. 密钥交换：

    • Alice 和 Bob 交换公钥曲线
    • 各自使用自己的私钥计算共享曲线
    • 共享密钥基于共享曲线生成

特点：

  • 交换性质：φ_A(φ_B(E)) = φ_B(φ_A(E))
  • 私钥由小素数组成，便于实现
  • 公钥尺寸小，适合实际应用

安全性：

  • 目前尚未被成功破解
  • 被认为比 SIDH/SIKE 更安全
  • 但仍存在潜在的安全风险

安全性分析

抗量子性

  • 量子算法抗性：

    • 目前没有已知的量子算法可以有效解决超奇异同源路径问题
    • 但 Grover 算法可能提供二次加速

  • 已知攻击：

    • 2022 年，SIKE 被成功破解
    • 攻击利用了同源图的特殊结构
    • 暴露了同源密码学的安全性弱点
安全边界

  • 参数选择：

    • 参数选择直接影响安全性
    • 不当的参数选择可能导致方案被破解

  • 同源图结构：

    • 同源图的结构可能被利用进行攻击
    • 研究人员正在探索更安全的同源图结构

性能与效率分析

计算效率
  • 密钥生成：相对较慢，需要计算多个同源
  • 密钥交换：计算复杂度高，特别是对于大安全参数
  • 封装/解封装：SIKE 的性能较差，CSIDH 相对较好
存储需求
  • 公钥：小尺寸（几百字节），这是同源密码学的主要优势
  • 私钥：相对较小（几十字节到几百字节）
  • 密文：尺寸适中（几百字节）
带宽需求
  • 公钥传输：带宽需求小
  • 密文传输：带宽需求适中

应用场景

尽管面临安全性挑战，超奇异椭圆曲线同源密码学在以下场景仍有潜在应用。

  1. 密钥交换：

    • 用于建立安全通信的会话密钥
    • 适合带宽受限环境

  2. 轻量级加密：

    • 公钥尺寸小，适合资源受限设备
    • 如物联网设备、传感器等

  3. 后量子安全升级：

    • 提供多样化的安全保障

  4. 匿名通信：

    • 同源密码学的某些特性可用于构建匿名通信系统

优势：

后量子密码学的标准化进程

为推动后量子密码学的实用化，美国国家标准与技术研究院（NIST）自 2016 年起启动了后量子密码算法标准化进程，目前已进入第三轮。

已选定的标准算法

NIST 于 2022 年 7 月公布了第一批后量子密码标准算法：

  1. CRYSTALS-Kyber（密钥封装机制）

    • 基于格基密码学
    • 用于 TLS 等协议的密钥交换
    • 性能接近传统 RSA/ECC 算法

  2. CRYSTALS-Dilithium（数字签名）

    • 基于格基密码学
    • 适用于证书和身份认证
    • 提供高强度的安全性保障

  3. FALCON（数字签名）

    • 基于格基密码学
    • 适合对签名尺寸有严格要求的场景
    • 签名尺寸小于 Dilithium

  4. SPHINCS+（数字签名）

    • 基于哈希基密码学
    • 提供长期安全性保障
    • 适合对安全性有极高要求的应用

候选算法

NIST 还在评估以下候选算法：

  • Classic McEliece（编码基密钥封装机制）
  • BIKE（编码基密钥封装机制）
  • HQC（编码基密钥封装机制）

TLS/SSL 协议

  • 确保物联网生态系统的安全性

国家安全与敏感信息保护

  • 保护政府和军事通信
  • 确保敏感数据的长期机密性
  • 维护国家关键基础设施安全

  • 确保云服务提供商与用户之间的安全通信
  • 支持安全的多云环境

后量子密码学的迁移策略与最佳实践

短期策略（1-3年）

  • 风险评估：识别核心系统中依赖量子脆弱算法的组件
  • 混合加密：采用 "传统算法+后量子算法" 的混合加密方案
  • 试点项目：在非关键系统中测试后量子密码算法
  • 加密库更新：使用支持后量子密码的加密库（如 OpenSSL 3.0+）

中期策略（3-5年）

  • 标准适配：根据 NIST 标准更新加密库和协议
  • 基础设施升级：更新支持后量子密码学的硬件和软件
  • 员工培训：提高团队对后量子密码学的认识和理解
  • 合规准备：了解并满足相关行业的后量子密码合规要求

长期策略（5年以上）

  • 全面部署：在所有系统中采用后量子密码算法
  • 持续监控：跟踪量子计算和密码学的最新发展
  • 安全更新：根据新威胁及时调整加密策略
  • 量子安全架构：构建完全基于后量子密码的安全架构

后量子密码学的挑战与未来

主要挑战

  1. 兼容性问题：需要与现有密码系统共存和过渡
  2. 性能影响：部分后量子算法的计算和存储开销较大
  3. 部署复杂性：需要更新全球范围内的基础设施
  4. 长期安全性：量子计算技术的发展速度存在不确定性
  5. 标准化进程：需要平衡安全性、性能和可实现性

未来发展方向

  1. 轻量化算法：针对物联网等资源受限设备优化
  2. 抗量子 TLS：推动 TLS 1.3+ 支持后量子密码
  3. 后量子区块链：开发完全抗量子的区块链技术
  4. 量子安全多方计算：结合后量子密码与多方计算技术
  5. 抗量子哈希函数：设计专门抵抗量子攻击的哈希函数

结论

五条技术路线的落地状态差异明显：格基的 Kyber、Dilithium、FALCON 与哈希基的 SPHINCS+ 已被 NIST 选定为标准算法，编码基的 Classic McEliece、BIKE、HQC 仍在候选评估中，多变量和同源两条路线尚未产出标准算法。被攻破的方案集中在多变量与同源两条路线上：Oil and Vinegar（1998）、SFLASH（2007）、SIKE（2022）。

迁移可以按常规依赖升级来做：先识别系统中依赖 RSA/ECC 的组件并评估其数据需要保密多久，再在协议层引入混合加密方案（传统算法 + 后量子算法），最后按 NIST 标准更新加密库与协议。
