哈希函数与数据完整性验证

哈希函数的核心特性与工作流程，MD 系列、SHA 系列到 SHA-3、BLAKE2 的演进与原理，以及文件完整性验证、密码存储、消息认证码(MAC)的应用与安全挑战。

对称加密算法详解

对称加密的工作流程与核心设计权衡，Feistel 网络等经典范式，DES/3DES 到 AES/ChaCha20 的演进，ECB 到 GCM、ChaCha20-Poly1305 的加密模式，以及算法选择、密钥管理与性能优化。

消息认证码技术详解

消息认证码的原理与功能，HMAC、CMAC、Poly1305、GMAC 的实现与安全特性，与数字签名的区别，以及在安全通信协议、API 接口认证中的应用。

非对称加密与公钥基础设施(PKI)

非对称加密的工作流程与核心设计权衡，RSA、DH 到 ECC 的演进与原理，PKI 的证书颁发机构(CA)、注册机构(RA)、数字证书与信任链，以及应用实践与优化策略。

数字签名技术与实践

数字签名的定义、真实性/完整性/不可否认性三大特性与签名验证流程，RSA、DSA 到 ECDSA、EdDSA 的算法演进，在身份认证、软件签名、电子合同与区块链中的应用，以及密钥管理与量子计算威胁。

现代密码协议与应用

把加密算法、哈希函数、数字签名等原语组合成端到端的安全机制：密码协议的安全目标与威胁模型，IPsec、SSH、TLS/SSL、OpenPGP 的实现原理，HTTPS、邮件加密、VPN、安全远程访问四类场景下的协议选择，以及协议漏洞与后量子迁移。

后量子密码学简介

后量子密码学（Post-Quantum Cryptography, PQC）研究抵抗量子计算机攻击的密码算法。量子计算对现有公钥密码体系的威胁（Shor 算法、Grover 算法的影响）、格基/哈希基/编码基/多变量/超奇异椭圆曲线同源五条技术路线、NIST 后量子密码算法标准化进程，以及 TLS、区块链、物联网等领域的应用前景与迁移策略。
