## 路线（边做边补）

1. **双均线**：用 vectorbt 跑通「金叉买 / 死叉卖」—— [双均线策略回测](./dual-ma/)
2. 自己写一个 150 行极简回测，把引擎从黑盒变白盒
3. 真正该自己写的是策略层与评估层：因子、组合、绩效归因、风控
4. 模拟盘 + 决策日志（防止自己骗自己）

## 几条硬标准（判断「真实」与否，不看出手写没手写）

- 真历史数据
- 真交易约束：A 股 T+1、涨跌停、手续费、滑点、印花税
- 样本外测试（参数别只在一段历史上好看）
